# Today

The tab the app opens on. Under the date and "day N of your plan", cards from other features (slot `today.cards`):

| Card | From |
|---|---|
| Reminders today (move meat to the fridge, soak rice) | Prep |
| Tonight's dinner | Cook |
| Lunch today | Lunches |
| Prep session today | Prep |
| Main shop / top-up today | Shopping |
| How was last night? | Feedback |

At the bottom, the week at a glance. Before the plan starts, or after it ends, it offers to see the week or plan the next one.

**Requires:** week. **Saves:** nothing.
