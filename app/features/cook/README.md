# Cook

The **Cook** tab: one card per night, starting with tonight. Each has how much rice to cook, then the quick methods for the main, side and soup. Anything that couldn't fit in a prep session shows first, as "Before you start". At the bottom: rice and food-safety notes.

- **Slot `cook.night`**: extras under a night (Feedback adds Liked / Okay / Skipped).
- **Slot `cook.sections`**: sections below the nights (Lunches adds the lunch plan).
- Today shows tonight's dinner. Adds page 5 of the printed plan.

**Requires:** week. **Saves:** nothing.
