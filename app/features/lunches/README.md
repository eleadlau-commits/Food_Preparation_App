# Lunches

Each dinner is cooked as 4 portions, and half is packed for the next day's lunch (`rules.js`): the main, the side (unless it's a salad that doesn't pack) and rice, with a tip on keeping or reheating it.

Adds the **Lunch plan** below the nights on the Cook tab (`cook.sections`), **Lunch today** on Today, and the lunch table to the printed plan.

**Requires:** week. **Uses:** cook. **Saves:** nothing.
